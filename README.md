# Learnzo

**Homework Help That Helps You Understand.**

An AI-powered homework-learning platform for parents and school students (CBSE, ICSE, State Boards).

## Status

Built module by module. Module 1 (Project Foundation) is complete.

## Local development (Windows)

1. Install Node.js 20 LTS from https://nodejs.org
2. Open cmd, go to the project folder, and run:

    npm install
    npm run dev

3. Open http://localhost:3000

## Scripts

| Script | Purpose |
|---|---|
| npm run dev | Start the development server |
| npm run build | Production build |
| npm start | Run the production build |
| npm run lint | ESLint |
| npm run typecheck | TypeScript type check |
