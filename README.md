# Learnzo

**Homework Help That Helps You Understand.**

An AI-powered homework-learning platform for parents and school students (CBSE, ICSE, State Boards).

## Status

Built module by module. Module 1 (Project Foundation) is complete.

## Local development (Windows)

1. Install Node.js 20 LTS from https://nodejs.org
2. Open cmd, go to the project folder, and run:

    npm install
    npm run dev

3. Open http://localhost:3000

## Scripts

| Script | Purpose |
|---|---|
| npm run dev | Start the development server |
| npm run build | Production build |
| npm start | Run the production build |
| npm run lint | ESLint |
| npm run typecheck | TypeScript type check |
## Supported curricula

Learnzo is designed around the Indian school education ecosystem.

- **Framework**: NCERT National Curriculum Framework, aligned with NEP 2020
  and the 5+3+3+4 structure set by the Department of School Education &
  Literacy (DSEL).
- **Boards**: CBSE, ICSE, and State Boards (SCERT-based).
- **Classes**: 6 to 12.
- **Subjects**: Mathematics, Science (Physics, Chemistry, Biology) and English.

Learnzo is an independent product and is not affiliated with or endorsed by
DSEL, NCERT, CBSE, ICSE or any State Board. Curriculum alignment reflects the
public frameworks published by those bodies.
